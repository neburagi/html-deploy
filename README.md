# VRボクシング革命

32歳男性のための革新的フィットネスソリューション。自宅で始めるVRボクシングに関する情報サイトです。

## 特徴

- 科学的根拠に基づいたVRボクシングの効果解説
- 心血管系の改善、ストレス軽減、カロリー消費などの詳細データ
- 32歳からの健康投資としての経済効果分析
- 継続しやすい運動習慣としてのVRボクシングの利点

## 技術スタック

- HTML5
- CSS (Tailwind CSS)
- JavaScript

## 開発方法

```
npm install
npm start
```

## デプロイ

このプロジェクトはGitHub Pagesを利用してデプロイされています。
