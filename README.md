# VRボクシング革命

32歳男性のための革新的フィットネスソリューション。自宅で始めるVRボクシングに関する情報サイトです。

## 特徴

- 科学的根拠に基づいたVRボクシングの効果解説
- 心血管系の改善、ストレス軽減、カロリー消費などの詳細データ
- 32歳からの健康投資としての経済効果分析
- 継続しやすい運動習慣としてのVRボクシングの利点

## プロジェクト構造

このプロジェクトはシンプルな静的ウェブサイトとして構築されています：

- `index.html` - メインのHTMLファイル
- 画像ファイル（直接ルートディレクトリに配置）
- `package.json` - 開発環境の設定

## 技術スタック

- HTML5
- CSS (Tailwind CSS)
- JavaScript

## 開発方法

リポジトリをクローンした後、以下のコマンドで開発サーバーを起動できます：

```
npm install
npm start
```

ブラウザで `http://localhost:3000` にアクセスすると、サイトがプレビューされます。
